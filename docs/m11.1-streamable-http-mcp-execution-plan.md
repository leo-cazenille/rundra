# M11.1: Authenticated Streamable HTTP MCP

Extend the optional `rundr-mcp` adapter with SDK-native Streamable HTTP while
preserving stdio as the default. HTTP startup requires one opaque bearer token
loaded from an environment variable, explicit DNS-rebinding host policy for
non-loopback listeners, and TLS termination at a reverse proxy.

Implementation milestones:

1. Add typed transport settings, constant-time static-token verification, and
   strict launcher validation without changing MCP tools or operation schemas.
2. Add SDK ASGI authentication, host/origin protection, launcher contracts,
   and protocol-level tests.
3. Document reverse-proxy and Open WebUI configuration, security boundaries,
   token rotation, and a bounded end-to-end smoke test.

OAuth, dynamic client registration, embedded TLS, unauthenticated HTTP,
per-user tokens, and per-tool scopes remain out of scope.
