# M27 v0.1.2 release preparation plan

## Goal

Freeze and validate the version 0.1.2 source and distribution artifacts without
tagging, pushing, or publishing them.

## Scope

- Move the completed Unreleased changes into a dated 0.1.2 changelog section
  while retaining an empty Unreleased section for subsequent work.
- Align project metadata, the uv lock, repository status, and release checklist
  on version 0.1.2.
- Run the complete infrastructure-free source checks required by the repository.
- Build the wheel and source distribution twice, compare their SHA-256 values,
  audit the public privacy boundary, validate package metadata, and smoke-test
  the wheel in a clean Python 3.12 environment.
- Keep generated artifacts outside version control. Do not create a Git tag,
  push commits, invoke a release workflow, or contact a package index.

## Acceptance

- Tests, Ruff lint/format, and strict mypy checks pass.
- Two independent builds are byte-identical.
- The audited wheel and sdist contain only the intended public package surface.
- A clean wheel installation reports `rundr 0.1.2` and renders CLI help.
- Publication remains an explicit later owner-authorized operation.
