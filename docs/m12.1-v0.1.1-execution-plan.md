## Objective

Link the installed agent guide to public package documentation, correct the
TestPyPI/production release split, and add a reproducible 1,000-Task local Slurm
system test without expanding the public scheduler surface.

3. Add a restricted-capability Docker Compose SSH/Slurm/Apptainer cluster.
4. Exercise worker pooling, compute-node placement, sharded retrieval, and
