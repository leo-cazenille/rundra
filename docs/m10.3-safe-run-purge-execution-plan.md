# M10.3 - Safe Run Purging

## Goal

Add an idempotent, auditable `rundr purge` command that deletes only an exact
terminal Run's framework-owned outputs or workspace. RunRecords, caches,
retrieved destinations, and external scheduler logs remain untouched.

## Implementation

- Add backend-neutral purge request/result models and local/SSH adapters.
- Rename selected data to a fixed tombstone before recursive deletion so an
  interrupted operation can resume safely.
- Require exact Run-ID confirmation for mutation; provide a network-aware,
  non-mutating dry run.
- Store strict atomic purge receipts separately from immutable RunRecords.
- Expose receipt history through purge and inspect JSON while preserving
  unchanged inspect documents for Runs without purge history.
- Serialize explicit fetch and purge actions with a per-Run operation lock.

## Validation

- Unit-test path containment, symlinks, tombstone resumption, idempotency,
  confirmation, lifecycle checks, receipts, SSH command construction, and JSON.
- Integration-test local and fake-SSH purge lifecycles.
- Run the full test, Ruff, formatting, mypy, and local-example checks.
